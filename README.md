# Amazon Sales Performance Analysis (Excel)

## Project Overview
This project analyses Amazon sales data to identify revenue drivers, regional performance patterns, and fulfilment efficiency using Microsoft Excel.

## Objectives
- Identify top-performing product categories
- Analyse sales trends across regions
- Evaluate fulfilment methods and their impact on sales
- Provide actionable business insights

## Tools Used
- Microsoft Excel
- Pivot Tables
- Conditional Formatting
- Data Cleaning & Transformation
- Basic Dashboarding

## Key Insights
- A small number of product categories contribute the majority of total sales revenue.
- Amazon-fulfilled orders show more consistent performance compared to merchant fulfilment.
- Some regions generate high order volumes but lower revenue, indicating pricing or product mix issues.
- Returns and cancellations represent potential revenue leakage.

## Recommendations
- Increase focus on high-performing product categories.
- Optimize fulfilment methods to improve reliability.
- Reassess pricing strategies in low-revenue regions.
- Reduce order cancellations through operational improvements.
